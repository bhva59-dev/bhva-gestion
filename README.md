# BHVA Gestion

Application de gestion de la Boucherie El Fen (SAS BHVA) : affichage des prix (HP A4 / Brother 62 mm), traçabilité, calendrier DLC, commandes clients, factures et BL, stocks, recettes.

- `index.html` : le comptoir (iPad, PC, employés)
- `prix.html` : Prix BHVA, l'application de gestion des prix (téléphone du responsable)

Site publié avec GitHub Pages.
